# Snapsong

Create a super duper consumer app where I can upload an image, it will extract context and use Nimble via https://www.nimbleway.com/ for even more context extraction, the AI model (Gemini, Astra or Opus 5.5) will list out the most favorable context for me to pick and I can also supply additional context (such as names, mood, etc.) and with all this info call Suno or Eleven Lab Music to generate songs. When playing the song, the song and lyrics will be played with the photo showing.
